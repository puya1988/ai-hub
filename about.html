关于 AI HUB · 智汇

一个纯静态、零依赖、可自由修改的人工智能信息聚合站点模板。

站点定位

AI HUB 的目标是把分散在新闻站、论文库、模型榜单、工具目录里的信息，重新按「用户想知道什么」组织起来。 它不是一个新闻媒体，而是一个索引与导航层：帮你快速找到该看什么、该用什么、该学什么。

内容板块
  • 资讯中心：按 9 大分类聚合行业动态
  • 模型库：24 个主流大模型档案与对比表
  • 工具导航：46 款 AI 工具按场景分类
  • 研究论文：里程碑论文 + 顶会信息
  • 学习路径：六阶段成长路线与资源
  • 术语百科：82 个核心词条中英对照
  • 发展史：AI 七十年关键节点时间线
技术特性
  • 纯静态：HTML + CSS + 原生 JS，无构建步骤
  • 零依赖：不引入任何第三方库或 CDN
  • 自动更新：脚本抓取 RSS，无需后端服务
  • 中英双语：en/ 完整英文站，语言切换保留当前页面
  • 定时部署：GitHub Actions 每日抓取 + 自动发布，无人值守
  • 响应式：桌面 / 平板 / 手机自适应
  • 深色模式 × 6 套配色，自由组合
  • 全站搜索：⌘K / Ctrl+K 唤起，本地索引
  • 模型横向对比：最多 4 个逐项对照
  • 可直接双击 index.html 打开（无需服务器）

数据来源与更新方式

本站内容按语言存放在独立文件中：中文 assets/js/data.zh.js， 英文 assets/js/data.en.js；界面文案统一放在 assets/js/i18n.js。页面渲染逻辑完全不包含内容， 因此更新资料不需要改动任何 HTML 或 CSS，也不会影响其他语言。

1
手工维护

直接编辑 data.js 中的数组，按现有字段格式追加条目即可。适合个人站点。

2
定时抓取（已实现）

运行 python3 scripts/fetch_news.py 抓取配置的 RSS 源， 输出 news-feed.js，配合 crontab 每日自动执行。

3
接口接入

改为 fetch 远程 JSON 接口，实现真正的实时更新，需部署到服务器。

具体字段说明与接入示例见 assets/js/README-数据接入.md。 英文站页面由 node scripts/build-en.js 生成，改文案请改脚本后重新生成。

更新日志

问题：站点此前只有列表页，没有详情页——卡片只是视觉容器，点击后无处可去。 资讯、模型、术语、时间线四类共 400 多个条目都无法打开。
修复：新增统一的内容详情弹层。有原文链接的条目（自动抓取的新闻）整卡可点、直开原文； 没有外链的条目点击后在站内打开详情，展示完整摘要、参数规格、标签与相关推荐， 并提供「官方文档」「搜索相关报道」「复制链接」等操作。
同时补齐：24 个模型全部补上官方文档链接；缺失官网的 2 个工具补上地址， 并把原来不可点的假按钮改为真正可用的搜索链接。
发现并修复：自动抓取的真实新闻热度只有 62–74，全部排在演示数据（74–98）后面， 英文站首页一度看不到任何真新闻。调整打分基准后，新抓到的条目正常进入前列。
新增工具：scripts/audit-links.js —— 一键审计全站死链与不可点击条目， 已覆盖中英双语 18 个页面共 420 个条目，结果为零问题。
1. RSS 自动更新：新增 scripts/fetch_news.py 与 scripts/feeds.json，支持抓取 10 个中英文源， 自动清洗、去重、分类、打标签，输出 assets/js/news-feed.js， 前端自动合并并在资讯页标记为「自动」条目。
2. 模型横向对比：模型库支持勾选最多 4 个模型，底部对比栏 + 逐项对照表， 自动高亮最优值，支持一键复制 Markdown；选择结果本地保存。
3. 多套配色：新增 6 套配色主题（靖蓝 / 深海 / 翡翠 / 紫罗兰 / 落日 / 石墨）， 与深色模式独立组合，顶栏一键切换并记忆。
4. 中英双语架构：界面文案抽离到 assets/js/i18n.js， 内容数据拆分为 data.zh.js 与 data.en.js， 新增完整英文站 en/（9 个页面，由 scripts/build-en.js 生成），顶栏可一键切换语言。 以后加日语、韩语只需新增一份数据文件 + 跑一次构建脚本。
5. 定时部署：新增 .github/workflows/， 「抓取 AI 资讯」每天自动抓取并提交，「部署到 GitHub Pages」自动发布； 另有 scripts/build-sitemap.js 生成中英双语 sitemap 与 robots.txt。推到 GitHub 后即可完全无人值守。
6. 修复：表格视图重新渲染后排序事件丢失；手风琴重复绑定导致点击无效； 部分环境下 localStorage 与 history API 报错导致主题/筛选失效。
建立 9 大内容板块：首页、资讯中心、模型库、工具导航、研究论文、学习路径、术语百科、发展史、关于。 实现全站搜索（⌘K）、深色模式、响应式布局、卡片/表格双视图、分类筛选与分页。
英文站 / 中英双语切换；模型榜单可视化图表；用户收藏与阅读历史； 资讯关键词订阅与邮件推送；导出为 Markdown / PDF。
