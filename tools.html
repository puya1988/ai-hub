新手路线

刚接触 AI，从哪里开始？

  1. 1. 先用一个通用对话助手（ChatGPT / Claude / DeepSeek / 通义）熟悉提问方式；
  2. 2. 把日常最耗时的一件事交给它，例如周报、表格公式、资料汇总；
  3. 3. 需要查资料时换用带引用的 AI 搜索（Perplexity / NotebookLM）；
  4. 4. 有编程需求再引入 IDE 级助手（Cursor / Copilot / 通义灵码）；
  5. 5. 对数据隐私敏感时，改用本地部署方案（Ollama / LM Studio）。
进阶路线

想把 AI 接进业务系统？

  1. 1. 明确场景与评测指标（准确率、延迟、单次成本）；
  2. 2. 用 Dify / LangChain / LlamaIndex 搭原型，先验证效果；
  3. 3. 接入向量库与重排序，构建 RAG 知识库（RAGFlow / AnythingLLM）；
  4. 4. 加一层 AI 网关做多模型路由、限流与计费；
  5. 5. 用 Langfuse 等工具做可观测性与持续评测，再考虑上量。
